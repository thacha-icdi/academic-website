# ระบบค้นหาฝึกงานแบบฟรี — เวอร์ชันปัจจุบัน

เว็บใช้ข้อมูลประกาศจากระบบรับสมัครของบริษัทมาแสดงในหน้าเว็บโดยตรง ไม่ต้องสมัคร Brave Search และไม่ต้องตั้งค่า API key
โค้ด Supabase internship-search เป็นแนวทางเดิมที่ไม่ได้ใช้ในเวอร์ชันนี้

## การใช้งาน
1. เปิดหน้า ค้นหาฝึกงาน
2. พิมพ์ชื่อตำแหน่งหรือบริษัท และเลือกจังหวัดได้ตามต้องการ
3. กด ค้นหาฝึกงาน เพื่อดูรายการที่ตรงเงื่อนไข
4. ปุ่มรายละเอียดเปิดประกาศต้นทาง ปุ่มเลือกและรายงานเปิดแบบฟอร์มขอจดหมายในระบบสำหรับนักศึกษาที่เข้าสู่ระบบแล้ว
5. คำขอจดหมายยังต้องติดตั้ง migrations/005-letter-requests.sql ใน Supabase ตามขั้นตอนเดิม

## ข้อมูล
- Greenhouse: Sertis, Agoda
- SmartRecruiters: Bosch Group, Minor International, Accor
- ดึงเฉพาะสถานที่ทำงานในประเทศไทยและมีหลักฐานว่าเป็นฝึกงาน
- ไม่อนุมานว่างาน Management Trainee เป็นฝึกงาน หากไม่มีประเภทงานระบุ Internship
- ตัดประกาศที่ชื่อระบุเฉพาะปีที่ผ่านมา และวันปิดรับที่ทราบว่าผ่านแล้ว
- แหล่งที่ดึงสำเร็จแต่อาจไม่มีฝึกงานจะมีจำนวน 0 ไม่ใส่ตัวอย่างแทน
- ไม่ครอบคลุมทุกบริษัท ทุกอาชีพ หรือทุกจังหวัด
- วันที่ในฟอร์มใช้วางแผน ไม่ได้ยืนยันว่าบริษัทรับในช่วงนั้น
- ต้องยืนยันเงื่อนไขและสถานะปัจจุบันกับบริษัทก่อนสมัคร

## การอัปเดต
GitHub Actions: .github/workflows/update-internships.yml
ตั้งรันทุกวัน 02:17 UTC (09:17 ประเทศไทย) และกด Run workflow เองได้
สคริปต์ scripts/update_internships.py ใช้ Python standard library ไม่ต้องติดตั้งแพ็กเกจหรือ secret
ข้อมูลอยู่ icdi-internship/data/internships.json
หน้าเว็บโหลดข้อมูลจาก raw.githubusercontent.com เพื่อรับข้อมูลที่ bot อัปเดตได้โดยไม่ต้องรอ Pages rebuild และใช้ไฟล์ใน Pages เป็น fallback

หากบางแหล่งขัดข้อง รอบนั้นจะไม่แสดงรายการจากแหล่งนั้น พร้อมแจ้งจำนวนแหล่งขัดข้อง
หากทุกแหล่งขัดข้อง สคริปต์ล้มเหลวและเก็บ snapshot เดิม เว็บไม่แสดง snapshot ที่เก่ากว่า 7 วัน
GitHub อาจเลื่อนเวลารันหรือหยุด schedule เมื่อ repo ไม่มี activity เป็นเวลานาน ให้ตรวจ Actions หากวันที่ข้อมูลเก่า

ส่วนเลือกตำแหน่งแสดงรายการหลัก ส่วนพิมพ์ค้นหาแสดงแหล่งเพิ่มเติมก่อน และย่อผลจากรายการหลักไว้ในกล่องแยก
ประกาศตรวจสอบเพิ่มเติมหมดอายุหลัง 7 วัน สคริปต์รายวันไม่ต่ออายุ checked_at อัตโนมัติ ต้องตรวจหน้าเดิมก่อนแก้วัน
เมื่อรู้ช่วงเดือนฝึกงานแน่นอน ระบบไม่แสดงรายการที่อยู่นอกช่วงวันที่ผู้ใช้เลือก ส่วนรายการไม่ระบุช่วงยังต้องยืนยันกับบริษัท
