# Research Data Source Finder

Website: https://thacha-icdi.github.io/academic-website/research-data-finder/

Enter a keyword and press Find to generate search links for data source websites: Google Dataset Search, Kaggle, UCI Machine Learning Repository, Zenodo, Harvard Dataverse, Hugging Face, Thailand Open Data, and DataCite Commons.

The page lists repositories, not research articles. It is a curated source directory: links carry the keyword to each provider's own search page. It does not crawl providers or verify that matching datasets exist. Some repositories also contain other research outputs; inspect resource type and licensing on the destination website.

Buildless HTML/CSS/JavaScript, hosted on GitHub Pages. Edit index.html in this folder to update the website. No API key, dependencies, or build step is required.
